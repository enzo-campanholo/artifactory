# D2 pitfalls

Generic pitfalls of D2 syntax. Several of them don't fail: they quietly draw something else, which is why every diagram goes through `pnpm look`. When a D2 mistake recurs, add a line here.

- **Quote any label with special characters.** In an unquoted label, `#` starts a comment (`a: C# code` draws "C"), `;` ends the statement (`a: um; dois` draws two shapes), `{…}` opens a container, and `[…]` fails. `a: "C# code"` draws it as written.
- **Dollar signs:** `$` starts a variable. Write the label in single quotes, `a: 'R$ 50'`, or escape it, `R\$ 50`. Double quotes still substitute.
- **Dots in keys nest:** `Na.K: bomba` draws a shape `K` inside a container `Na`. Give the shape a plain key and put the text in its label: `bomba: Na⁺/K⁺`.
- **Declare, then connect.** `a: Read -> b: Answer` draws one shape labelled "Read -> b: Answer". Label each shape on its own line, then write `a -> b`.
- **Keys are identities, labels are text.** `atp: ATP (energia)` lets connections say `atp -> adp` while the drawing shows the full label. Accented keys work, but plain ones are easier to connect.
- **Reserved keywords** (`label`, `shape`, `style`, `icon`, `near`, `direction`, `steps`, `layers`, `vars`, `classes`, …) can't be shape keys or connection ends. Quote them, or pick another key.
- **Steps build up.** Each board under `steps` inherits everything from the board before it, so a step's block holds only what that step adds. The stepper then shows each board whole, all in one frame the size of the largest board, so a part keeps its place from step to step.
- **Grid gaps are fixed.** A connection inside a `grid-columns` or `grid-rows` container runs across its `grid-gap`, and a label wider than the gap covers the line. Give a labelled grid a `grid-gap` wider than its longest label, such as `grid-gap: 100` for a word or two.
- **Direction:** `direction: right` lays the diagram out left to right. Phones are narrow, so a long chain reads better top to bottom (the default), or as a `grid-columns` container. A board much taller than it is wide prints small: past about 8 stages in a column, wrap them with `grid-columns`.
- **The design system's style:** the check fails a file that asks for what the design system doesn't draw, at the line that asks: colours written in the file (`style.fill`, `style.stroke` or `style.font-color` as `"#…"` or a colour name), `style.shadow`, `style.fill-pattern`, `style.animated`, `style.opacity` below 1, `sketch`, a legend (`vars.d2-legend`), and a `link`, `tooltip` or `icon`, or a link in a markdown label. Leave them out, and put links and explanations in the prose or the caption.
