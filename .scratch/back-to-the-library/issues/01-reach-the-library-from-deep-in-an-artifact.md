# 01: Reach the Library from deep in an artifact

Status: needs-triage
Blocked by: None (can start immediately)

Design-system work: run it in a local session with impeccable, after `PRODUCT.md` and `DESIGN.md`.

**Problem:** the only link back to the Library is in the running head. Deep in an artifact, the owner has to scroll all the way up, or jump to the first section and then scroll up a bit, to reach it.

**What to build:** a way back to the Library that is in reach from anywhere in the artifact, on phone and desktop.

- [ ] From any scroll position, the owner reaches the Library in one action, without scrolling.
- [ ] A draft leads back to the drafts page instead, as the running head's link does.
- [ ] A visitor's form gets no such link, as its running head has none.
