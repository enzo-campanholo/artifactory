## Code, mid-run

A Stage traces a function line by line on its one fenced code block, highlighted as anywhere else. The catalog script pressed Start on n = 6 and stepped to step 5, where the first pass halves n. Line 5, the line running, is reversed: a bar across the code's whole width, even where the long line 7 scrolls sideways. The `if` that just decided is strong, the `while` it tests again after this pass is dashed, and the `else` branch it didn't take is muted. The step is announced as "Step 5 of 36. Line 5. …".

<div data-catalog-run="start" data-catalog-step="5">

<Stage
  build="collatz"
  input={{
    label: "Trace collatz(n)",
    fields: [{ name: "n", min: 1, max: 99 }],
    examples: [{ n: 6 }],
  }}
  prompt="Type a number and press Start."
  caption="The Collatz steps of n, line by line."
>

```python
def collatz(n):
    steps = 0
    while n != 1:
        if n % 2 == 0:
            n = n // 2  # even: halve it
        else:
            n = 3 * n + 1  # odd: three times n, plus one, so the run climbs before it falls again
        steps += 1
    return steps
```

| Variable | Value |
| -------- | ----: |
| n        |     1 |
| steps    |     8 |

</Stage>

## A table that grows

A step's `body` replaces the rows of the Stage's one table, so a teste de mesa, the trace of a program written by hand, gains a row each time the loop runs. Each new row copies the last row as written, so it keeps the table's alignment and type, and the step's marks land on the rows `body` wrote. The catalog script pressed Start on n = 4 and stepped to step 6, the second pass: the row `2` is new, its f just written in bold, while n still shows 3 until line 5 runs. Going back drops the row again, and print and the page without JavaScript show the rows as written, the first example's result.

<div data-catalog-run="start" data-catalog-step="6">

<Stage
  build="factorial"
  input={{
    label: "Trace factorial(n)",
    fields: [{ name: "n", min: 0, max: 12 }],
    examples: [{ n: 4 }, { n: 0 }, { n: 12 }],
  }}
  prompt="Type a number and press Start."
  caption="The teste de mesa of factorial(n), a row per pass of the loop."
>

```python
def factorial(n):
    f = 1
    while n > 1:
        f = f * n
        n = n - 1
    return f
```

| Pass  |   n |   f |
| ----- | --: | --: |
| start |   4 |   1 |
| 1     |   3 |   4 |
| 2     |   2 |  12 |
| 3     |   1 |  24 |

</Stage>

</div>
