MEPA's machine trace: a Stage whose build is `trace(mepa, notes)`, running the listing written in its code block on the numbers typed. The listing works out a trapezoid's area, (a + b) × h div 2, with every instruction MEPA covers: `INPP`, `AMEM`, `LEIT`, `ARMZ`, `CRVL`, `SOMA`, `MULT`, `CRCT`, `DIVI`, `IMPR`, `DMEM`, `PARA` and `FIM`. The same program runs in a pt-BR Stage and in an English Stage, each with its tables as written in its language and its build's notes in that language too, so each says its steps in its own.

The catalog script pressed Start on a = 3, b = 5, h = 4 and stepped to step 12, where `SOMA` runs. Line 10, the instruction that ran, is reversed, and line 11, where `i` points next, is dashed. What the step changed is strong: `i`, `s`, the sum 8 in M[3] and `← s` moving to it from M[4]. M[4] is above `s`, so it's muted and shows no role. Without JavaScript and in print, each Stage shows its tables as written: the first example's last step, where `DMEM 3` has freed every cell, so none shows a role or the top.
