MEPA's machine trace: a Stage whose build is `trace(mepa, notes)`, running the listing written in its code block on the numbers typed. The listing works out a trapezoid's area, (a + b) × h div 2, with every instruction MEPA covers: `INPP`, `AMEM`, `DSVS`, `ENPR`, `CRVL`, `MULT`, `CRCT`, `DIVI`, `ARMZ`, `RTPR`, `NADA`, `LEIT`, `SOMA`, `CHPR`, `IMPR`, `DMEM`, `PARA` and `FIM`. It opens as a compiler lays out a program: `DSVS L1` jumps over the function área(bases, altura) to `L1: NADA`, the main program's start. The main program reads a, b and h, reserves a cell for the return value, pushes a + b and h as the arguments and calls `CHPR L2,1`. `ENPR 1` sets `D[1]` to the record's base, the function reads its parameters at offsets −5 and −4 (`CRVL 1,-5`), stores the area in the return value at −6, and `RTPR 1,2` returns with it on top. A label names its line's address; the build's `labels` note names its place, said when a jump or a call lands there and when the run passes the `NADA`, and its `subroutines` note gives área's parameters and its return value, so the memory table's `Desl.` column shows each record cell's offset. The same program runs in a pt-BR Stage and in an English Stage, each with its tables as written in its language and its build's notes in that language too, so each says its steps in its own.

The catalog script pressed Start on a = 3, b = 5, h = 4 and stepped to step 24, inside área, where `ARMZ 1,-6` stores the area 16 in the return value's cell. Line 9, the instruction that ran, is reversed, and line 10, the `RTPR` where `i` points next, is dashed. What the step changed is strong: `i`, `s`, the 16 in M[3] and `← s` moving to M[8] from M[9]. The record runs from M[3], the return value at offset −6, through the parameters at −5 and −4 and the return address, the level and the kept `D[1]` at −3 to −1. M[9] and M[10] are above `s`, so they're muted and show no role or offset. Without JavaScript and in print, each Stage shows its tables as written: the first example's last step, where `DMEM 3` has freed every cell, so none shows a role, an offset or the top.
